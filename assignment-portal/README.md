# Student Assignment Portal (PHP + Supabase Postgres, on Vercel)
- Student side: register / login / see faculty assignments / submit / view marks and feedback
- Faculty side: `/faculty` (default `faculty` / `faculty123` - change it under Faculty > Profile): assignments CRUD, grading, students, CSV export
- Env vars: `DB_HOST`, `DB_PORT=5432`, `DB_USER`, `DB_PASS`, `DB_NAME=postgres`, `DB_SCHEMA=student_portal`
- Framework Preset: Other. No build command.
